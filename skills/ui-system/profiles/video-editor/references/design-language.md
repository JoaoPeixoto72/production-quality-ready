# Video Editor — Design Language

This profile is dark-first. Dark chrome avoids contaminating the perception of
video material.

Profile-specific expectations:

- warm amber accent that does not compete with footage hues;
- pure-black preview canvas (`--canvas-void`);
- numeric and timecode rendering with tabular figures;
- restrained motion and limited elevation;
- typography built around Instrument Sans + JetBrains Mono when the consumer
  actually ships those fonts locally.
