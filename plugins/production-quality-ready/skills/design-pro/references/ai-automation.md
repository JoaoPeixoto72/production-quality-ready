# AI Features Inside a Product

This guide covers AI features embedded in a traditional product — the "Summarize" button, the recommendation row, the smart filter, the AI search. The product itself is not an agent; AI just augments its surfaces.

For products that ARE agents (the user delegates work rather than operating controls), use `./ai-agent.md`.

## Checklist

| Item | Guidance |
|---|---|
| AI feature entry point | Clear, labeled, discoverable. Example prompts shown for chatbots. |
| Scope communicated | The feature says what it can and cannot do before the user tries. |
| Smart recommendations explainable | "Because you liked X" + "Not interested" option always visible. |
| AI-powered search | Supports natural language. Shows what the AI understood from the input. |
| Predictive input non-intrusive | Tap to accept, ignore to dismiss. Never auto-inserts. |
| Auto-categorization editable | Shows the AI's label + lets the user correct inline. |
| AI summaries labeled | Marked as AI-generated. Link to the original source. |
| Consistent AI badge | Same badge everywhere (sparkle icon widely recognized). Near content, not buried. |
| Per-feature opt-out | In Settings. Not a single global "Disable AI" toggle. |
| Graceful degradation | Low-confidence output says less, offers options — never one confident wrong answer. |
| Feedback loop | Thumbs up / down on every AI output. Minimal friction. |
| On-device for sensitive content | Photos, notes, health data processed locally where possible. |
| Model change disclosure | Users informed when the model powering a feature changes significantly. |

## AI UX principles

- **Explainability.** Answer "why am I seeing this?" — proactively or on demand.
- **Graceful degradation.** When confidence is low, the AI says less, not more.
- **Progressive trust.** Start conservative. Let users see the system improve with their use.
- **User in the loop.** AI proposes, user decides. Never irreversible actions without confirmation.
- **Transparency by default.** Every piece of AI-generated content is labeled and traceable.

## Content labeling

Consistent badge across the whole product. Near the content, not buried in metadata. Tap or hover reveals: "This was generated by AI." Never mix AI-generated and human-created content in one feed without differentiation.

## Feedback loop design

| Type | Pattern |
|---|---|
| Micro | 👍 / 👎 on hover or long-press. "Was this helpful?" at end of AI responses. |
| Macro | Periodic prompt after ~7 days of use. Dedicated feedback in Settings > AI. |

Where possible, close the loop: "Your suggestions have been used to improve your recommendations."

## On-device vs cloud

| Criterion | On-device | Cloud |
|---|---|---|
| Privacy | High — data stays on device | Lower — data sent to server |
| Latency | Very low | Depends on connection |
| Capability | Limited by device hardware | Full model capability |
| Cost | Model download once | Per-inference cost |
| Best for | Photos, text suggestions, classification | Chat, generation, summarization |

## Anti-patterns

- AI features with no way to opt out.
- Recommendations without a "Why?" explanation.
- AI-generated content mixed with human content, indistinguishable.
- Confidently wrong single answers where the model should have said "I'm not sure — here are options".
- Raw model errors exposed to users.
